# ADR-16 Project docs moved from Notion to the Obsidian vault MechAi

Back to [Decision Log](Decision%20Log.md)

**Status:** Accepted

**Context:** The project documentation was first written in Notion, whose free plan ran out of blocks.

**Decision:** All documentation lives in this Obsidian vault. Sharing it is decided in [ADR-33 Docs shared through a private GitHub repository; internal notes kept apart](ADR-33%20Docs%20shared%20through%20a%20private%20GitHub%20repository;%20internal%20notes%20kept%20apart.md).

**Why:** Plain Markdown files that the team owns; works offline; versionable with git.

**Alternatives considered:** Staying in Notion with a paid plan; Google Docs.

**Consequences:** The Notion pages are no longer maintained.
