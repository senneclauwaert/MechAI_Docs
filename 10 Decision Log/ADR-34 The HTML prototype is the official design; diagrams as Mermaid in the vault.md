# ADR-34 The HTML prototype is the official design; diagrams as Mermaid in the vault

Back to [Decision Log](Decision%20Log.md)

**Status:** Accepted

**Context:** Several designs existed: the HTML prototype, the Figma file, a separate UI from 28 October and a FigJam board.

**Decision:** The HTML prototype is the official design reference. The 28 October UI was rejected and deleted. Diagrams live in the vault as Mermaid code; FigJam is no longer used. Figma stays as design history. Amended the same day: Senne chose a new look for the prototype (light-blue accent, dark navy sidebar, cards that lift on hover), so the Figma colours are no longer the reference.

**Why:** One reference avoids contradictions; Mermaid diagrams stay in sync with the text and show on GitHub.

**Alternatives considered:** The 28 October UI; Figma as the reference; FigJam diagrams.

**Consequences:** The prototype was updated for the 6 November decisions and restyled on 6 November 2026 (version 6). See [HTML prototype (official)](../06%20Design%20and%20Prototypes/HTML%20prototype%20%28official%29.md) and [Diagrams](../06%20Design%20and%20Prototypes/Diagrams.md).
