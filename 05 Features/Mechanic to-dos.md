# Mechanic to-dos

Back to [Features](Features.md)

## User story

As a mechanic, I see the open to-dos per kart and the ones assigned to me, including ones made from an issue.

## What it includes

- Create, assign (optional) and close tasks per kart, also from an issue in one tap.
- The system can create to-dos, for example for low stock.
